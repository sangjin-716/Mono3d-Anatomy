# Cross-benchmark preliminary audit (Waymo, nuScenes)

Scripts behind supplementary Sec. P and the "Other Benchmarks" paragraph of Sec. 5.1. This is a **preliminary audit, not a replication**: one released checkpoint per detector, no confidence intervals, and only the reproduction step has an external reference (the re-sort has none). Its magnitudes are not compared with the KITTI band or across detectors. Summary with sources: `reports/extensions/crossbench_audit.md`.

Pipeline, in four steps:
1. **Checkpoints / predictions.** Waymo: the released Waymo val predictions of GUPNet and DEVIANT (DEVIANT release, runs 1050/1051) and of MonoRCNN++. nuScenes: FCOS3D and PGD via mmdetection3d `tools/test.py` with `configs/*_dump_full.py` (official config, evaluator swapped for `DumpResults`); CenterNet as CenterTrack's `nuScenes_3Ddetection_e140` checkpoint (`test.py ddd`); EPro-PnP-Det basic via `run_epropnp_infer.sh`. Environments: `setup_nuscenes_stage1.sh`, `setup_centertrack3.sh`, `setup_epropnp.sh`.
2. **Reproduction gate on the unmodified official evaluator.** Waymo: `waymo_v2_to_kitti_gt.py` (GT from the v2 parquet release; checks in `gt_adversarial_gates.py`), then `run_gate.sh` + `waymo_eval_patched.py` / `waymo_eval_0_5_patched.py`, deltas in `gate_deltas_v2.py`. nuScenes: `run_repair.sh` (PGD) and `nusc_official_reformat.py` (FCOS3D) through the official mmdet3d formatter; `nusc_official_eval.py` (CenterNet, via `night_queue.sh`) and `xds_nusc_official_eval.py` (EPro-PnP-Det) on each release's own json; `pgd_bisect_eval.py` + `nds_residual.py` locate PGD's NDS excess in the TP-error terms. `campkl_to_nusc_json.py` / `run_ib_gates.sh` are the superseded hand-written path; no paper number uses them.
3. **Conversion to per-camera box pools.** `ct_to_oracle_pkl.py` (CenterTrack json, whose height convention it matches) and `xds_nusc_json_to_oracle_pkl_FIXED.py` (spec-conforming jsons: EPro-PnP-Det, FCOS3D, PGD); checks: `align_check*.py`, `xds_*_check.py`, `gate_content_equality.py`; boxes per image: `pool_census.py`, `pred_census.py` / `run_census.sh`.
4. **True-IoU re-sort of each unchanged Car pool** at IoU3D 0.7, all-point AP: `waymo_core_analysis.py` (Waymo, repository evaluator) and `nusc_oracle.py` (nuScenes, mmdet3d 3D IoU), driven by `run_chain_{fcos3d,pgd}_oracle.sh` and `run_ct_oracle_chain2.sh`.

External data and code (none shipped): Waymo Open Dataset v2 validation parquet (`lidar_box`, `projected_lidar_box`, `camera_calibration`, `vehicle_pose`) under `paths.WAYMO_ROOT/waymo_v2/validation`, with the converted GT in `waymo_kitti/` (plus the `waymo_gtorg/validation_org/<segment>/label_0/` re-layout the evaluator reads) and predictions in `predictions/`; nuScenes v1.0-trainval (val split, 6,019 samples) at `paths.NUSC_ROOT` with mmdet3d's `nuscenes_infos_val.pkl`; under `paths.UPSTREAM_ROOT`: DEVIANT (Waymo `ImageSets`, released Waymo runs), mmdetection3d 1.4.0 (FCOS3D, PGD), EPro-PnP (EPro-PnP-Det), CenterTrack, and `checkpoints/`. Shell scripts read these through `_paths.sh`; set `PYTHON` to the interpreter of the matching environment. Everything here is compile-checked only in this release.
